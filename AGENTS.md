# Distribution repository

Only distribution documentation belongs in this Git repository. Never copy private implementation source, research, credentials, local paths or source Git history here. Upload reviewed binary packages as Release assets, not Git contents.

Before every push, list the source path, branch, commits, target remote, actual push URL and target branch, and obtain explicit approval for that range. Public binary publication also requires an approved version and file list. Do not trigger paid CI or alter billing settings without authorization.
